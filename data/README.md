# Dataset setup

Download **Online Retail II** from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online%2Bretail%2Bii).

Save the original workbook as:

```
data/online_retail_II.xlsx
```

The workbook is intentionally **not committed** to GitHub. The repository provides the analysis code and source attribution, not a redistributed copy of the underlying dataset. Verify the Excel file's sheet names and headers against the script before relying on the outputs.

Data cover 2009–2011 and are **historical, not TikTok Shop transactions**.
